# Visualizer Flow

Music into motion.

## Qué hace
- Convierte un MP3/WAV en un visualizador musical animado.
- Genera una combinación visual aleatoria al abrir la app.
- “Otro estilo” crea una combinación nueva sin usar presets fijos.
- Incluye 3 animaciones, 3 paletas, 3 fondos, 3 tipografías y controles de posición/intensidad.
- Mantiene las opciones avanzadas retraídas para que el flujo normal sea rápido.
- Preview de 20 segundos.
- Exportación WEBM con audio.
- 9:16, 4:5, 1:1 y 16:9.
- Todo funciona del lado del cliente y es compatible con GitHub Pages.

## Uso
1. Abre `index.html` en Chrome o Edge.
2. Sube un MP3 o WAV.
3. Reemplaza artista, título y texto secundario si quieres.
4. Pulsa “OTRO ESTILO” si quieres otra combinación.
5. Abre “OPCIONES AVANZADAS” solo si quieres personalizarla.
6. Exporta el WEBM.

## Nota
La exportación actual es WEBM porque es el formato estable de la implementación del navegador. No se agregó una conversión MP4 para no introducir servidores ni dependencias externas.
