# MP3 to WEBM — Video Visualizer

Versión funcional para GitHub Pages.

- MP3/WAV directo en el navegador
- Preview real de 20 segundos
- Exportación WEBM con audio
- Objetivo de captura 60 FPS
- Resoluciones: 1920×1080, 1080×1920, 1080×1350 y 1080×1080
- Visualizadores: espectro, onda, partículas y minimal
- Barra de progreso durante exportación
- Sin backend ni servidor

## Archivos
`index.html`, `style.css`, `app.js`

## Nota
WEBM es el formato de exportación principal porque MediaRecorder no garantiza MP4 en todos los navegadores sin procesamiento adicional.
